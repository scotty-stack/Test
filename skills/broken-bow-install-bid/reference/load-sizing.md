# Load Sizing

Estimate truck volume from the order list to test the one-trip plan.

**These are planning estimates, not quotes.** Use the owner's own numbers from past loads where available — they beat this table. Always show which items were estimated and which came from actual box dimensions.

---

## Method

1. Use actual box dimensions from vendor listings or packing slips when available (L x W x H in inches / 1728 = cubic feet).
2. Otherwise estimate by category using the owner's past-load figures in the rate card or past job notes.
3. Add a packing-inefficiency factor — loads never pack perfectly. Ask the owner what they use; if none is given, say so and show the total with and without it.
4. Compare to usable cubic feet of the truck/trailer in the rate card.

## Report

```
Estimated load:  ~___ cu ft (__ items from box dims, __ estimated by category)
Truck capacity:  ___ cu ft (<truck name> from rate card)
Fit:             yes / tight / no
Largest items:   <list — these decide whether a piece fits the door and stairs too>
```

If no box dimensions and no past-load figures exist, don't make up per-item volumes. Ask the owner how many truckloads a similar cabin took last time — that's usually the fastest and most accurate answer.

## Trash volume

Packaging is usually bulky. Estimate it from the owner's past jobs (e.g. "a 4BR fill-out was one full trailer of cardboard"). Record that figure in the rate card notes so future bids use it.
