# Preliminary Overview — for new leads

Use before the client has a final purchase list. It shows the whole project without committing to numbers. Format: a Google Doc in the owner's Drive, one per client, titled "<Street> – Cabin Install Overview". The owner shares it view-only with downloading, printing and copying turned off.

---

## Sections, in order

1. **Header:** client names, cabin size, new build or refresh, date. Add a one-line note: "This is an overview, not a final bid. Exact numbers follow your final purchase list."
2. **How it works (six steps, one trip):** finalize the purchase list → everything ships to us → we store it until install → one trip to Broken Bow → install and style → haul off and hand over.
3. **Who does what:** two columns, the client and us.
4. **Bird's-eye timeline:** list finalized → deliveries arrive → receiving cutoff 7 days before load → install days on site → hand-off. Weeks are approximate and labeled that way.
5. **Situation checklist**
   - New build: builder punch list done and cleared for occupancy; post-construction clean; power, water and HVAC on; truck access on new drives; doorway and stair measurements; studs or blocking for TVs and heavy art.
   - Refresh: what happens to the existing furniture; work around the guest booking calendar.
6. **How pricing works:** rates only. 15% of the final order total (adjusts with the order); U-Haul at U-Haul's rate for the truck size; $200 per helper per day; lodging and travel at cost; flat trash haul-off fee; receiving, inspection and storage **Included**.
7. **Try your numbers (optional):** the client enters an estimated order total and sees the 15% fee and the included value (4% of goods + storage at OKC 10x10 rates). Any default figure is labeled as an example.
8. **Next step:** what's needed for the exact bid (final list, floor plan or photos, builder completion date and first booking date, address and access), plus the deposit and late-item (second trip) terms.

## Rules

- No totals for the job, only rates and a clearly labeled example.
- Never call a storage space "climate-controlled" unless it is.
- Draft only. The owner shares it.
- Signed with the owner's own name only. Never use the real estate team name (OREC advertising rules).
